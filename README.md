# Visual Defect Inspection SaaS

Multi-tenant building inspection: defect detection on site photos, engineer review and PDF site reports.

Built by [AOX](https://automatedoperationsexperts.com). Status: in development.

## Run it

Phase 1 adds a one-command start: `docker compose up` with seeded sample data,
plus a mock mode that replays recorded model responses so no API key is needed.
